# Skill: ATR Dynamic Risk Manager (ATR 動態風險控管器)

## 1. 技能概述 (Overview)
此技能旨在將量化分析中的 **平均真實波幅 (ATR)** 轉化為可執行的交易計畫。它不只是提供一個價格，而是根據標的的即時波動率計算「適合投入的張數」與「科學的停損位」。

## 2. 核心邏輯 (Core Logic)
*   **數據來源**：串接 `quant_service.analyze_stock` 獲取標的的 `ATR` 與 `price`。
*   **資金配置**：預設單筆投入預算為 **10,000 TWD** (`sip_amount_twd`)。
*   **停損係數**：
    *   台股/美股：`price - (2.5 * ATR)`
    *   加密貨幣：`price - (3.0 * ATR)` (應對較高波動)
*   **數量換算**：根據預算自動計算股數（台股支援零股）。

## 3. 輸入參數 (Input Parameters)
| 參數 | 類型 | 描述 | 預設值 |
| :--- | :--- | :--- | :--- |
| `symbol` | String | 標的代號 (如: 2330, AAPL, btcusdt) | 必填 |
| `market_type` | String | 市場類型 (TW, US, CRYPTO) | TW |
| `budget` | Float | 本次交易預算 (TWD) | 10,000 |

## 4. AI Agent 範例指令 (Prompt Example)
> "請幫我分析 **[SYMBOL]**。調用 `analyze_stock` 接口獲取其 14 日 ATR 數據，並根據 $10,000 TWD 的預算計算：
> 1. 當前股價下的建議買進數量。
> 2. 基於 2.5x ATR 的初始停損價位。
> 3. 若最近 5 日 ATR 異常放大 (ATR5 > 1.5x ATR)，請在報告中特別標註「波動異常，建議縮減部位」。"

## 5. 輸出範例 (Output Example)
*   **標的**：台積電 (2330)
*   **現價**：$600
*   **ATR (14D)**：$12.5
*   **建議操作**：
    *   **買進股數**：16 股 (約 $9,600)
    *   **初始停損**：$568.7 (2.5x ATR)
    *   **風險等級**：中等 (波動穩定)
*   **AI 叮嚀**：目前位階處於 52 週中段 (50%)，建議在回測月線守穩後再執行定額投入。
