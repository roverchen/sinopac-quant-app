# Skill: MA20 Support Scanner (月線支撐掃描器)

## 1. 技能概述 (Overview)
此技能專注於尋找處於「強勢回檔」階段的標的。根據 Eric 的交易邏輯，最強大的買點通常發生在股價回測月線 (MA20) 且守穩時。此技能會從全市場掃描結果中，自動篩選出股價貼近月線支撐且動能尚未轉弱的標的。

## 2. 核心篩選邏輯 (Filtering Logic)
*   **支撐距離 (MA20 Diff)**：股價與月線的距離需在 **-1% ~ +3%** 之間。
*   **動能過濾 (MACD)**：MACD 柱狀體 (Histogram) 需為正值，或斜率 (Slope) 正在回升（代表回測即將結束）。
*   **流動性要求**：台股日成交量需 > 10M TWD。
*   **位階限制**：排除處於 52 週極高位階 (>90%) 的標的，以防末升段誘多。

## 3. 輸入參數 (Input Parameters)
| 參數 | 類型 | 描述 | 預設值 |
| :--- | :--- | :--- | :--- |
| `market_type` | String | 市場類型 (TW, US, CRYPTO) | TW |
| `tolerance` | Float | 容許距離月線的百分比 | 2.0% |

## 4. AI Agent 範例指令 (Prompt Example)
> "執行 `MA20 Support Scanner`。請從最新的台股海選結果中，挑選出股價距離月線 2% 以內、且 MACD 柱狀體正在收斂的標的。請列出前 5 名評分最高的候選清單，並附加 ATR 風險評估。"

## 5. 輸出範例 (Output Example)
*   **發現標的**：欣興 (3037)
*   **距離月線**：+0.5% (極度貼近)
*   **技術特徵**：縮量回測月線，MACD 柱狀體負值收斂中。
*   **風險評估**：建議買點 $180，停損 $168。
