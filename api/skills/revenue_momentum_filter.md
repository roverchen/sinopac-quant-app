# Skill: Revenue Momentum Filter (營收動能濾網)

## 1. 技能概述 (Overview)
此技能旨在從基本面出發，確保所選標的具備實質的成長動能。技術面指標雖然能反映價格走勢，但「營收成長」才是支撐股價長期上漲的核心驅動力。此技能會自動檢索標的最近三個月的營收 YoY (年增率) 趨勢。

## 2. 核心邏輯 (Core Logic)
*   **數據來源**：串接 `FinMind` 或 `quant_service.check_revenue_momentum`。
*   **篩選標準**：
    *   **連續增長**：最近三個月營收 YoY 呈現遞增趨勢。
    *   **絕對強度**：最新月份營收 YoY 需 > 10%。
*   **整合評分**：將營收動能作為「加分項」，若營收表現極佳且技術面同時觸及 MA20 支撐，則視為「黃金交叉標的」。

## 3. 輸入參數 (Input Parameters)
| 參數 | 類型 | 描述 | 預設值 |
| :--- | :--- | :--- | :--- |
| `symbol_list` | List | 待驗證的標的清單 | 海選 Top 20 |
| `min_yoy` | Float | 最低營收年增率要求 | 10% |

## 4. AI Agent 範例指令 (Prompt Example)
> "執行 `Revenue Momentum Filter`。請檢查目前台股海選前 10 名標的的營收趨勢。排除營收 YoY 正在衰退的標的，並優先推薦營收年增率超過 20% 且技術面評分高於 60 分的標的。"

## 5. 輸出範例 (Output Example)
*   **績優標的**：台積電 (2330)
*   **營收趨勢**：
    *   M-2: +15%
    *   M-1: +18%
    *   Current: +22% (強勁增長)
*   **結論**：基本面支撐強勁，技術面回檔為加碼良機。
