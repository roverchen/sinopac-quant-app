# Sinopac Quant App (金融商品市場報明牌系統)

這是一個強大的多市場（台股、美股、加密貨幣）資產篩選與模擬交易系統。本系統採用「權重動態配置」策略，透過價值防禦與強勢動能兩大維度，為使用者即時篩出最佳標的，並提供自動與手動下單模擬機制。

---

## 🔐 帳戶管理與憑證設定 (Account & Credentials)

本系統支援多人模式，每位使用者皆擁有獨立的儲存空間與個人設定。

### 1. 登入機制 (Authentication)
* **暱稱登入**：首次使用只需輸入您的暱稱與密碼，系統會自動為您建立專屬環境。
* **安全性**：密碼採用 SHA-256 加希隆雜湊存儲於伺服器端，確保個人隱私。
* **資料持久化**：所有 API 金鑰與自選股清單皆存在伺服器端 JSON 檔案中，不受瀏覽器清除快取影響。

### 2. 交易憑證設定 (Credentials Setting)
您可以在側邊欄點擊 **「🔒 交易憑證設定」** 面板進行配置：
* **永豐金 (Sinopac)**：提供 API Key 與 Secret，並可上傳 PFX 憑證檔案（系統會自動加密轉換為 Base64 存儲）。
* **MAX 交易所**：提供 API Key 與 Secret，用於即時獲取加密貨幣餘額。
* **身分證/憑證密碼**：用於實盤交易下單時的身分驗證。

### 3. 設定前後的差異 (Mode Differences)

| 功能特性 | 💡 離線恢復模式 (未設定) | ✅ 全功能模式 (已設定) |
| :--- | :--- | :--- |
| **名稱解析** | 使用本地快取名單 (`name_map.pkl`) | 即時連線 API 同步最新合約 |
| **數據掃描** | 僅限 Yahoo Finance 公開數據 | 支援 Shioaji 高速報價與分析 |

## ⚖️ 權重動態配置與買點計算策略

系統的「權重動態配置與買點計算邏輯」是整個選股引擎的核心，具體運作原理如下：

### 1. 雙引擎計分：價值防禦 vs 強勢回測
系統為每檔標的計算兩種不同維度的分數，總分滿分 100 分。

#### 🛡️ 價值防禦分數 (Value Score)
* **核心精神**：尋找「跌深、安全邊際高」的標的。
* **計算基礎**：
    * **一年位階 (Level Percentile)**：目前價格距離過去一年的最高點與最低點的位置。越靠近最低點，基礎分數越高（最高 50 分）。
    * **均線乖離加分**：如果價格非常貼近「防禦均線」（台股預設為 240 日年線，若無則降級使用 60 日季線；加密貨幣預設使用 100 日均線），代表有強力底部支撐，額外加 **30 分**。
    * **成交量動能加分**：當價格站在 5 日均線上，且**最新成交量大於 5 日均量的 1.2 倍**時（代表底部出量），額外加 **20 分**，避免買在死水區卡死資金。

#### 📈 強勢拉回分數 (Pullback Score)
* **核心精神**：尋找「多頭趨勢中剛剛回檔休息」的飆股。
* **計算基礎**：
    * **MA20 乖離度**：計算目前價格與 20 日均線（月線）的距離。價格越貼近月線（乖離度越接近 0），分數越高（最高 50 分）。代表股票剛好拉回月線支撐。
    * **MACD 狀態加分**：判斷 MACD 柱狀圖。如果出現「**金叉**」（柱狀圖由負轉正），給予額外加分。演算法內含「**0 軸濾鏡**」：快慢線皆在 0 軸之上（強勢區金叉）加 **50 分**；在 0 軸之下（弱勢區金叉）僅加 **30 分**。

### 2. 權重動態配置 (Dynamic Weight)
系統利用側邊欄的「**策略偏好：成長 ↔ 防禦**」滑桿（滑桿值範圍 0~1）來融合上述兩個分數：
```python
綜合評分 = (防禦權重 * 價值分數) + ((1 - 防禦權重) * 強勢分數)
```
* **偏向防禦時**：跌深的股票容易入選，系統推薦的點位會偏向年線/低點的左側交易。
* **偏向成長時**：多頭強勢整理的股票容易入選，系統推薦的點位會偏向月線的右側交易。

### 3. 精確買賣點與風報比計算 (Entry & Exit)
系統會動態判斷該標的最後是「強勢分數佔優」還是「價值分數佔優」，來決定給出哪套進出場劇本：

* **當「價值防禦」勝出時 (左側抄底)**
    * **建議買價**：目前價格與「防禦均線(年線)」取較低者。
    * **目標價 (停利)**：防禦均線 或 買價的 **+20%**。
    * **停損價**：過去一年最低點再往下切 5% (`year_low * 0.95`)，作為終極防線。

* **當「強勢回測」勝出時 (右側順勢)**
    * **建議買價**：精確等於 **20 日均線 (月線)**。
    * **停損計算 (引進 ATR 真實波幅)**：系統會計算近 14 日的平均真實波幅 (ATR)。停損點設在「目前價格減去 2.5 倍的 ATR」（加密貨幣為 3.0 倍）。這代表**如果部位波動率變大，停損空間自動拉開以免被洗出場；波動小時停損則會變窄**。
    * **動態風報比 (停利)**：預設給予 **1:3** 的風險報酬比（冒 10 元風險賺 30 元）。如果加密貨幣出現兩倍以上的爆發量，系統會更貪婪地將風報比拉高至 1:4。

### 4. 終極濾網：營收趨勢審查 (Revenue Momentum)
為了避免買到單純因為業績爛而暴跌的「價值陷阱」，系統會在最後一刻串接 FinMind API 查詢台股標的**近三個月的營收 YoY (年增率)**：
1. 取出近三個月的 YoY 數據。
2. **衰退判定**：如果連續三個月 YoY 越來越差（如 +5% -> -2% -> -10%），**且**最新一個月 YoY 是負值。
3. **砍分懲罰**：只要判定為連續衰退，該股票的「綜合評分直接乘以 0.1（打一折）」。
也就是說，不管技術面看起來多像底，只要基本面營收連續衰退，系統就會將其從推薦榜單中剔除。

## 🤖 系統自動執行下單模擬 (全域機制)

系統內建一套嚴格遵守紀律的「模擬交易機器人」，所有活動皆公開記錄於「交易紀錄儀表板 -> 系統自動執行 (全域共享)」中。

### 1. 自動進場邏輯 (Entry)
* **觸發時機**：當任何使用者在畫面上點擊三大海選按鈕（**「🇹🇼 台股」、「🇺🇸 美股」、「🪙 加密」**）進行全市場掃描時。
* **選股標準**：系統會根據當下側邊欄設定的「**策略偏好權重（成長 vs 防禦）**」對全市場標的進行評分與排序。
* **自動買入**：系統會毫不猶豫地挑選該次掃描**總分第一名（Top 1）**的標的，自動建立一筆「系統級別」的模擬買單，並記錄當時的推薦理由與價格。這筆訂單為全域共享，所有使用者都能看到這筆官方推薦持倉。

### 2. 自動出場機制 (Exit)
系統會在每次有行情數據更新時，背景自動檢查目前「系統自動」帳戶內的未平倉位。
* **🛑 停損設定 (Stop Loss)**：當未實現損益（預估報酬率）**≤ -5%** 時，觸發強制停損。
* **🎯 停利設定 (Take Profit)**：當未實現損益（預估報酬率）**≥ +20%** 時，觸發達標停利。
* **執行方式**：與「個人手動」部位達標時只會跳出提醒通知不同，**系統部位只要觸碰到上述兩個條件之一，就會「全自動強制平倉」**，計算最終損益並將該筆交易移入歷史結算紀錄中。

**結論**：系統就像一個無情的交易機器人，每次海選就大膽買入第一名，買入後虧損 5% 就砍，賺到 20% 就收。使用者可以此作為觀察這套嚴格紀律策略長期勝率與期望值的官方基準。
